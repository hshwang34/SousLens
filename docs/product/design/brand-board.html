Rules that don't bend

Glass goes here

  • Tab bar (minimises on scroll)
  • Navigation toolbars, search
  • Cooking tools and Back / Next
  • Sheet backgrounds (the assistant drawer)

Never on glass

  • Recipe text, ingredients, step text
  • Allergy blocks, food-safety notices, swap cautions
  • Error and offline banners, confirmation dialogs
  • Animation never hides or auto-dismisses a safety message
